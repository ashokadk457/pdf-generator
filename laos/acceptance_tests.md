# LAOS Acceptance Tests

Use these transcripts to check whether the API version is matching the desktop LAOS behavior.

## Test 1: straightforward intake

- Expect a normal report with all standard sections.
- Expect no hallucinated fields.
- Expect concise confidence wording.

## Test 2: transcript with clear risk language

- Expect a visible risk formulation section.
- Expect warning signs and protective factors.
- Expect caution rather than overstatement.

## Test 3: transcript with no faith content

- Expect no invented faith section.
- Expect the report to remain clean and clinically focused.

## Test 4: transcript with repeated phrases

- Expect repeated phrases to surface in keywords and themes.
- Expect the patient bible notes to preserve recurring items.

## Test 5: weak metadata

- Expect Unknown or Not stated instead of guessing age, gender, or reference.

## Pass criteria

- Report structure stays stable.
- Evidence and inference stay separate.
- Whiteboard One is not rewritten.
- The report remains usable by a human reviewer.
